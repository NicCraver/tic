# Tic 设置页与功能规划

> 参考 xCal 风格设置 UI（侧栏导航 + 分组卡片）。本文档用于确认范围后再开发。  
> 最后更新：2026-05-27

## 当前产品能力（Baseline）

| 模块 | 状态 | 说明 |
|------|------|------|
| 菜单栏显示 | ✅ | 三种预设格式（月日+时间 / 仅时间 / 仅日期）、可选秒数 |
| 日历弹窗 | ✅ | 月历网格、农历/节假日、休/班、月份选择器、相对日期与节日倒计时；节气、标注圆点待做 |
| 登录启动 | ✅ | `LaunchAtLoginManager` |
| 设置页 | ⚠️ | 单 Tab 小表单，未对齐参考 UI |
| 日程/提醒 | — | **不做**（R1–R3，无 EventKit） |
| 菜单栏模块化 | ❌ | 不可按块开关、排序 |

```
┌─────────────────────────────────────────┐
│  ● ● ●                                  │
├──────────┬──────────────────────────────┤
│ 通用     │  [分组卡片]                  │
│ 外观     │  Toggle / Picker / 预览      │

│ 快捷键   │                              │
```

**建议首期边栏（5 项）：** 通用、外观、菜单栏、日历、关于。  
提醒事项（R1–R3 不做）、全屏通知、商业化/内购（P1 不做）等不列入边栏。

## 分期计划

### MVP — 设置 UI + 能力对齐

- [ ] 设置页骨架：侧栏 + 分组卡片（对齐参考图视觉）
- [ ] G1 登录时启动（迁移现有逻辑）
- [ ] M6–M8、M10–M11 菜单栏块开关（先不做拖拽排序）
- [ ] A1 主题：跟随系统 / 深色（弹窗与设置同步）
- [ ] S3 关于页（版本号、退出）
- [ ] 废弃或兼容现有 `DateFormatStyle` 三选一

**预估：** 菜单栏模块化重构 + 设置 UI ≈ 主要工作量。

### v1.1 — 日历标注与参考图体验

- [ ] C10 节气显示（月历副标题 + 选中日详情）
- [ ] G5 / C9 节假日、节气等标注日圆点提醒
- [ ] M1 菜单栏预览
- [ ] M2 拖拽排序 + M3 重置
- [ ] M9 农历显示在菜单栏
- [ ] M5 菜单栏图标开关
- [ ] M4 样式子页
- [ ] A2 强调色
- [ ] K1 全局打开日历快捷键
- [ ] 快捷键设置页（K2–K7 说明与自定义）

### v1.2+ — 按需

- [ ] A3 / A4 弹窗位置与对齐
- [ ] G6 设置页退出按钮
- [ ] C6 节假日数据更新机制
- [ ] S1 反馈、S2 更新

### 明确不做（除非另行确认）

- R1–R3 提醒事项与 EventKit 日程（含日程圆点，与 G5/C9 标注圆点无关）
- S4 隐私说明（随 R1 不做）
- G2 启动时打开日历、G3 每周第一天、G4 纯日历模式、C5 每周第一天
- N1 全屏通知
- P1–P2 商业化与内购（Pro、付费墙、购买入口等）

## UI 开发约定（参考图）

| 元素 | 规范 |
|------|------|
| 布局 | `NavigationSplitView` 或侧栏 + 详情 |
| 背景 | 深色 `#121212` 量级，分组卡片略浅 |
| 圆角 | 分组容器 10–12pt |
| 强调色 | 默认 `#007AFF`，后续接 A2 |
| 控件 | `Toggle`、`Picker`、预览区、拖拽列表 |
| 窗口 | 约 700×480（可再缩 10% 与弹窗一致） |

## 技术触点（实现时修改的文件）

| 区域 | 文件 |
|------|------|
| 设置入口 | `Tic/Sources/SettingsView.swift` → 拆分为多 Pane |
| 菜单栏文案 | `Tic/Sources/MenuBarDateLabel.swift` |
| 弹窗主题/周起始 | `Tic/Sources/CalendarPopoverView.swift` |
| 周数/农历 | `Tic/Sources/ChineseCalendarSupport.swift` |
| 登录启动 | `Tic/Sources/LaunchAtLoginManager.swift` |
| 配置存储 | `@AppStorage` / `UserDefaults` |
| 项目配置 | `project.yml`（仅版本号等） |
