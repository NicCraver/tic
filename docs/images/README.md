# 截图素材清单

README 顶部引用以下三张截图，文件补齐后即自动显示，**无需改动 README**。
请用 Retina 屏（@2x）截取、导出 **PNG**（避免 JPEG 噪点），深/浅色任选其一并保持一致（建议**深色**，与应用默认弹窗观感一致）。

| 文件名 | 内容 | 拍摄建议 | README 显示宽度 |
|--------|------|----------|------|
| `menu-bar.png` | 菜单栏标签本体 | 仅截取状态栏中 Tic 标签局部（含左右少量留白），不要整条菜单栏 | ~420px |
| `calendar-popover.png` | 点击标签弹出的月历弹窗 | 含头部月份/年份、休/班标注、节气、底部详情与节日倒计时；选中「今天」 | ~300px |
| `settings.png` | 设置窗口 | 打开「菜单栏」或「日历」分区，体现侧栏 + 分组卡片 | ~300px |

## 操作步骤

1. 运行 `scripts/restart-dev.sh`（或 Xcode 中 ⌘R）启动 Tic。
2. **菜单栏标签**：用「截图」App 或 ⌘⇧4 框选状态栏中标签区域。
3. **弹窗**：点击菜单栏标签弹出月历 → ⌘⇧4 后按 **空格** 选中弹窗（连带阴影）。
4. **设置**：从弹窗齿轮按钮或 ⌘, 打开设置窗口 → ⌘⇧4 + 空格选中窗口。
5. 按上表文件名保存到本目录 `docs/images/` 即可。

> 三张图建议统一外观模式与缩放比例，排版更整齐。
